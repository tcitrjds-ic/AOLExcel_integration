# CSV選考データマージツール

3種類の選考CSV（**2次選考 / 最終選考 / 内定出し**）から「日時」と「氏名」を抽出し、
1つのCSVに集約するTkinter製のデスクトップツールです。

## セットアップ

```powershell
pip install -r requirements.txt
```

## 起動

```powershell
python csv_merger.py
```

## 使い方

1. アプリ起動後、画面に3つの枠（`＜2次選考＞` / `＜最終選考＞` / `＜内定出し＞`）が表示されます。
2. 各枠に対応するCSVファイルをドラッグ&ドロップします（枠あたり複数CSV可、1枠のみでもOK）。
3. 「マージしてCSV出力」ボタンを押すと、`~/Downloads/merged_YYYYMMDD_HHMMSS.csv` に保存され、
   エクスプローラーで該当ファイルが選択状態で開きます。

### 出力フォーマット

| 列 | 内容 |
| --- | --- |
| 日時 | `yyyy/M/d HH:mm` 形式に整形（パース不能な値は元の文字列のまま） |
| 姓 | 元の氏名を最初の空白で分割した前半 |
| 名 | 元の氏名を最初の空白で分割した後半（区切りが無い場合は空） |
| 種別 | `2次選考` / `最終選考` / `内定出し` |

## 抽出ルール

| 枠 | 日時 列名（優先） | 日時 位置（フォールバック） | 氏名 列名（優先） | 氏名 位置（フォールバック） |
| --- | --- | --- | --- | --- |
| 2次選考 | `2次選考` | C列 | `グループ選考 【総合評価】（ユーザ）` | H列 |
| 最終選考 | `最終選考会` | D列 | `最終 【総合評価】（ユーザ）` | J列 |
| 内定出し | `内定だし（＝面談）` | E列 | `内定通知 1.入社させたいか（ユーザ）` | L列 |

- **列名優先**: ヘッダーに該当列名が見つかればそれを使用
- **位置フォールバック**: 列名が一致しない場合、アルファベット位置で取得
- **姓名分割**: 全角スペース（U+3000）または半角スペースで分割。区切りが無い場合は全て姓列に格納
- **氏名が空白の行**は出力から除外
- **時刻自体は絶対に変更しません**（表記の整形のみ）

## AOL送信CSV出力

「AOL送信CSV出力」ボタンは、マージ結果の各人物を**社員一覧→所属一覧→AOL ToとCc一覧**の
3ファイルで突き合わせ、宛先（To/Cc）付きの送信用CSVを生成します。

### リファレンスファイル（Downloads配下の同名ファイルを初期値）

| ファイル | 役割 | 主な列 |
| --- | --- | --- |
| 社員一覧 (CSV) | 氏名 → 所属名称 | A=社員名 / B=所属 |
| 所属一覧 (XLSX) | **所属名称 → 本部名称 の変換表** | B=所属名称 / D=本部名称 |
| AOL ToとCc一覧 (XLSX) | 本部名称 → To/Cc氏名 | A=本部コード / B=本部名 / C=To / D=Cc |
| 個別送信テンプレート (XLSX) | 件名・本文・添付・BCCの既定値 | 2行目に既定値 |

### 突き合わせの流れ

```
氏名 ──(社員一覧)──▶ 所属名称 ──(所属一覧)──▶ 本部名称 ──(AOL ToとCc一覧)──▶ To/Cc
```

- **所属一覧による橋渡し**: 社員一覧 B列の所属名称（例: `スクール２１大宮本部` / `ＩＴ室` /
  `個別一宮`）は、AOL ToとCc一覧の本部名称（例: `スクール21大宮本部` / `IT室` /
  `個別尾張本部`）と表記が一致しないため、所属一覧で **所属名称 → 本部名称** へ自動変換してから
  宛先を引きます（全角↔半角・校舎名→本部集約などを吸収）。
- 所属一覧に該当が無い所属は、保険として所属名そのものを本部名として照合します。
- 変換後の本部名がAOL ToとCc一覧に無い／Toが居ない／時刻変換ルールが無い等の行は出力せず、
  `aol_send_skipped_YYYYMMDD_HHMMSS.csv` に理由付きで記録します。

## 文字コード

- 入力: 自動検出（`utf-8-sig` → `cp932` → `utf-8` → `latin-1` の順で試行）
- 出力: `utf-8-sig`（BOM付き、Excelで文字化けせず開けます）
